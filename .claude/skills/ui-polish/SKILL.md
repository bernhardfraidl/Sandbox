# UI Polish Skill

Nutze diesen Skill fuer UI-/Designpruefungen einer bestehenden Web-App.

## Ziel

Die vorhandene Oberflaeche verbessern, nicht neu erfinden.

## Pruefen

- Design-Konsistenz bei Farben, Abstaenden und Typografie
- Lesbarkeit einzelner Module und Komponenten
- mobile Bedienung, besonders auf kleinen Smartphones
- klare Vorschau-, Dialog- und Freigabefenster
- Touch-Ziele und Abstaende
- Lesbarkeit bei kleinen Displays
- keine ueberladenen Fenster
- klare Status- und Fehlermeldungen

## Grenzen

- Keine neue App-Konzeption beginnen, wenn nur Polish gefragt ist.
- Keine Deployments.
- Keine produktiven Daten veraendern.
- Keine externen Design-Assets ohne Freigabe uebernehmen.

## Ergebnisformat

Berichte:

- konkrete UI-Probleme
- Prioritaet
- betroffene Screens oder Komponenten
- empfohlene Verbesserung
- mobile Risiken
