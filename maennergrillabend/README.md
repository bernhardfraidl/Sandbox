# Männergrillabend – Übergabepaket für Claude Code

## Inhalt

- `PROMPT_CLAUDE_CODE.md` – vollständiger Arbeitsauftrag
- `assets/people/` – ausschließlich hochgeladene Originalfotos
- `assets/reference/onepage_mockup.png` – aktueller Einseiten-Entwurf
- `assets/reference/bbq_style_reference.png` – Stilreferenz für Grill, Feuer und Bier
- `assets/reference/photo_approval_reference.png` – ältere Freigabeübersicht
- `config/people.json` – verbindliche Namen, Dateien und Ausschnitt-Hinweise

## Verwendung

Den kompletten Ordner in das Arbeitsverzeichnis von Claude Code kopieren.

Danach Claude Code diesen Auftrag geben:

`Lies zuerst PROMPT_CLAUDE_CODE.md und setze den Auftrag lokal um. Verwende config/people.json verbindlich für die Originalfotos.`

## Verbindliche Bildregel

Die Dateien in `assets/people/` dürfen nicht durch KI-generierte oder retuschierte Bilder ersetzt werden.
Es sind nur CSS-Größenanpassung, kreisförmige Darstellung und sichtbarer Ausschnitt erlaubt.
